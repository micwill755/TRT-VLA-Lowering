Pi0.5 Export Pipeline Example
===============================

Physical Intelligence **Pi0.5** uses a three-stage Edge-LLM layout: vision, language,
and action. Unlike GR00T, the action head consumes language hidden states directly
(there is no separate ``action_context`` engine).

Quick start
-----------

From the project root:

.. code-block:: bash

   cd /path/to/Test
   export EDGE_LLM_PLUGIN_SO=/path/to/libNvInfer_edgellm_plugin.so

Export and benchmark in one command:

.. code-block:: bash

   python app.py --model pi05 --device cuda --engine-dir /tmp/pi05_edge_llm

Export and benchmark separately:

.. code-block:: bash

   python app.py --model pi05 --export-only --device cuda --engine-dir /tmp/pi05_edge_llm
   python app.py --model pi05 --benchmark-only --device cuda --engine-dir /tmp/pi05_edge_llm

Eager inference only:

.. code-block:: bash

   python app.py --model pi05 --inference-only --device cuda

Default checkpoint: ``lerobot/pi05_libero``. Override with ``--model-id``.

Pipeline stages
---------------

.. list-table::
   :header-rows: 1
   :widths: 12 20 24 44

   * - Stage
     - Engine directory
     - Inputs from
     - Responsibility
   * - ``0``
     - ``visual``
     - Runtime inputs
     - PaliGemma vision tower → image embeddings.
   * - ``1``
     - ``language``
     - Stage ``0``
     - Prefill with visual embeddings; emits LM hidden state and KV cache.
   * - ``2``
     - ``action``
     - Stage ``1``
     - Flow-matching denoising loop → robot actions (``final_output``).

.. mermaid::

   graph LR
       IN["runtime sample"]
       V["0 visual"]
       L["1 language"]
       A["2 action"]
       OUT["actions"]

       IN --> V --> L --> A --> OUT

Edge LLM runtime
----------------

Pi0.5 uses three engines (no ``action_context``). Language prefill exports
``prefix_k`` / ``prefix_v``; the action engine consumes them directly.

.. code-block:: bash

   export EDGELLM_PLUGIN_PATH=/path/to/libNvInfer_edgellm_plugin.so

   llm_inference \
     --engineDir=/tmp/pi05_edge_llm/language \
     --multimodalEngineDir=/tmp/pi05_edge_llm \
     --inputFile=/tmp/pi05_edge_llm/runtime_smoke/input_action.json \
     --outputFile=/tmp/pi05_edge_llm/runtime_smoke/output_e2e.json \
     --maxGenerateLength=0

Default export uses a static prefix of **830** tokens (3 image slots × 256 +
text/state). The C++ Paligemma tokenizer may not match Python token counts for
natural task strings — see :doc:`../edge_llm/e2e` for parity notes and smoke-test
paths.

Full binding contract: :doc:`../edge_llm/overview`, :doc:`../edge_llm/runners`,
:doc:`../edge_llm/bindings`.
